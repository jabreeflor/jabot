Enforce scoped frontend coverage and report Rust coverage

#230 / PR 254 — a unit floor that counts untested new files, honest about what it is not, and Rust reports without a premature threshold.

How it works

Before this change the audit at c898b8f already knew the unit number (93 / 85.5 / 81) and that client.ts looked thin in jsdom. Nothing enforced it, and Rust had no report at all.

Write src/NewView.tsx No test imports it.
→
verify unit + coverage all: true + include src/**/*.{ts,tsx}
→
Floor 90 / 85 / 80 Unimported file pulls the totals down. Gate fails.

The e2e project is not folded into that number. HostClient methods that unit tests stub are exercised over a live jabot-hostd; pretending the unit report is whole-product coverage is the lie this policy refuses.

Rust is a second report, not a second floor. First Linux baseline: 86.31% lines / 83.76% functions / 85.65% regions, including 0% process mains (jabot-hostd, Tauri lib.rs). CI installs llvm-tools-preview and cargo-llvm-cov in workflow setup, then sets JABOT_RUST_COVERAGE=1 so verify’s rust-tests stage is one instrumented run. scripts/coverage-rust.sh exits 2 if the binary is missing — it will not cargo install.

Why 90 / 85 / 80

Originally measured on Node 22.14.0 at the audit commit: 92.96% lines, 85.52% branches, 81.16% functions. CI is now Node 26 (#215); jsdom localStorage is handled by --no-experimental-webstorage. The proposed start is a hold-the-line floor with a few points of headroom, not a target to climb. #229 is on main; coverage is still a measurement, not a retry harness.

src/host/client.ts is 52% in unit because slices stub it. selectTransport and the hot-transport error path are already tested. The rest is one-line this.request(METHOD) wrappers and Tauri IPC — the host-protocol suite’s job. No method-mirroring tests were added to lift the number.

What to look at

  1. vitest.config.ts — include / exclude / thresholds / reportOnFailure.
  2. scripts/tests/coverage.test.sh — a throwaway fixture where an unimported file fails 90%, and covering it passes.
  3. .github/workflows/ci.yml — llvm-cov install in setup; artifact upload with if: always().
  4. scripts/coverage-rust.sh + scripts/verify.sh — offline gate; tool install stays in CI.
  5. docs/coverage.md — unit vs e2e, client.ts investigation, Rust high-risk gaps.

How to verify

npm run test:coverage:policy — fixture miss fails; excludes hold.

npm run test:coverage — unit suite, floors hold on Node 26.

./scripts/verify.sh — whole gate, including the unit floor. Local rust stays cargo test.

On the PR: download the coverage-reports artifact even from a red run. Open coverage/SCOPE.md first.
