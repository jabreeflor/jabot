JaBot · PR #206 walkthrough

Add a light theme for JaBot

The shipped UI stays graphite. Settings now offers Light and Match system. The preference is painted onto the existing design tokens before React mounts, so the first frame is already the chosen palette.

How it works

Before · one palette

:root owned every surface hex. There was no switch.

→

After · same names, two values

[data-theme="light"] reassigns --chat, --ink, --cream, --sunk… Components keep reading the names.

Darkjabot.theme = dark
Shipped default. Existing installs do not flip.
Lightjabot.theme = light
Cream-paper ground; cream chrome inverts so tabs still punch.
Match systemjabot.theme = system
Resolves via prefers-color-scheme. Opt-in OS follow.

The store is renderer localStorage, not settings/set. Theme has to be on <html> before the host answers — a round trip would flash graphite. An inline script in index.html and bootTheme() in main.tsx keep the first paint and HMR in agreement.

How to verify

  • Open Settings → General. Dark is selected on a fresh install.
  • Choose Light. Sidebar, chat, Settings, Pull Requests, and New Chat / the harness picker should all follow.
  • Relaunch: Light is still selected. The first frame is light, not a graphite flash.
  • Choose Match system and flip the OS appearance: the document’s data-theme should follow.
  • ./scripts/verify.sh on this tree (already green on the pushed revision).
  • Real-app shots live in docs/img/light-theme/.
