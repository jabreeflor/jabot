Add a Code conversation summary panel for repositories, Git state, and sources

The Code thread header now opens a compact popover of real host facts: which checkout this conversation is on, live +/− counts, Local + branch, Git actions aimed at that repo, extra attached folders, and sources.

How it works

Header Trigger names the selected repo. Open it and the panel asks the host — it does not guess from the transcript.
→
thread/summary Primary repo = the thread’s folder / worktree. Extra rows = thread_repos. Sources = thread_sources. Counts = live git vs the default-branch merge-base (HEAD fallback) plus untracked lines. Environment is always Local.
→
Actions keep a repo id Inspect / compare call thread/git/diff for the selected row (or a GitHub compare / PRs tab when a URL exists). Commit or push uses thread/git/commit and thread/git/push on that checkout. Sources open, add, and list through thread/source/*.

Selection is local UI state so it is obvious which row Git buttons apply to. Extra repos are other registered folders, not extra worktrees. The panel reloads on open, after mutations, on session/update, and every 4s while open. Empty, loading, unavailable, and non-Git folders are named sentences; Git buttons disable when there is no checkout.

Keyboard: labelled trigger and dialog, Escape dismisses (picker first, then the popover), pointer-down outside closes it.

How to verify

Open a Code thread on a Git folder. The header should name that repo. Open the summary: Changes, Local, branch, and the three Git actions belong to that checkout. Attach a second folder — it appears as a collapsed row; selecting it retargets counts and actions. Inspect opens the file list; Commit or push opens the commit modal; Compare uses a GitHub URL when present, otherwise the same review surface. Add a source (desktop file picker) or seed thread/source/add; View all lists them. Pick a non-Git folder: the status sentence appears and Git actions disable. Escape closes the popover.
