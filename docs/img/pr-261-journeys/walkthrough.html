Cover onboarding, streaming, fold, and permission journeys with Playwright

Six critical user journeys through the real renderer and Rust host. No second test stack — the #231 fixtures own Vite, jabot-hostd, and a temp data dir. This PR only adds the clicks.

How it works

Playwright Chromium → visible controls (role/label locators) React renderer → devTransport → Vite host-bridge Real jabot-hostd + SQLite in an owned temp dir fake-acp-agent modes: echo, pump, gated, permission, empty-reply, cancellable

RPC is only for prerequisites (seedCodeThread, crew/update) and independent host assertions (adapter log, inbox/list, permission/pending). The action under test is always a click or composer Enter.

pump is the one agent extension. gated already held a turn open; pump consumes the gate file so a test can write chunk:…, wait for the UI, write again, then end_turn. Streaming and scroll need that ordering.
