Lint macOS-only Rust on relevant PRs without a per-PR bundle

Linux Clippy never sees cfg(target_os = "macos") code, and the macOS bundle job is post-merge packaging. This PR turns the existing notify scratch-crate into an automatic PR check and adds a path-filtered native Clippy job only where Linux cannot reach.

How it works

Every PR · Linux macos lint plan Diff against the PR base. Match the lists in scripts/macos-lint-needed.sh. Write notify=0|1 and native=0|1. No Mac runner starts yet.
→
If notify=1 · Linux mac notify cross-check Same script as ./scripts/verify.sh --check-mac: scratch crate, objc2* only, Clippy -D warnings for x86_64-apple-darwin. Then inject a lint into a copy of mac.rs and prove it fails.
→
If native=1 · macOS macos clippy cargo clippy --locked --lib -- -D warnings on a real Mac. Covers Keychain and the updater / hide-to-Dock / Reopen branches. Cached. Not tauri build.
Why not one Linux command for everything?

Decision #73 / #109 already recorded this: cross-checking the whole Tauri crate fails because objc2-exception-helper needs an Apple cc. The notify scratch crate avoids that graph. Keychain and lib.rs do not, so they get the scoped Mac job instead of a per-PR bundle.

What to look at

FileWhy it matters
scripts/macos-lint-needed.sh Single inventory of which paths turn which job on. Shared Cargo/lock/toolchain/CI files turn both on.
scripts/check-mac-notify.sh Unchanged recipe from #109; CI now calls it. JABOT_NOTIFY_DIR lets the injected-lint proof use a copy.
scripts/check-macos-clippy.sh Native wrapper. Refuses to run on Linux so nobody mistakes a skip for coverage.
.github/workflows/ci.yml Named PR checks. Plan always runs; the 10x runner starts only when native=1.
docs/macos-lint.md Module inventory, local repro commands, deliberate exclusions.

How to verify

  • Default offline gate: ./scripts/verify.sh — includes the planner tests, not the network cross-check.
  • Which jobs would this branch start: ./scripts/macos-lint-needed.sh --base origin/main
  • Notify, from Linux: rustup target add x86_64-apple-darwin && ./scripts/check-mac-notify.sh
  • Native, on a Mac: ./scripts/check-macos-clippy.sh
  • Proof on CI run 34170052336: a ptr_arg in notify/mac.rs failed mac notify cross-check. That function is gone from this tree.
