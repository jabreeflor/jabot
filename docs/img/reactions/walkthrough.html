Add emoji reactions to bot chat messages

An agent's reply can now take a mark. The picker is the discoverable action; the badges under the bubble are the record. The store, not the live session, is the source of truth — so a remount or a restart draws the same set.

How it works

Before

  • AgentBubble rendered Markdown and nothing else.
  • There was no write path for a user-authored overlay on a transcript item.
  • Acknowledging a reply meant sending another turn.
→

After

  • Add reaction opens a short palette. Choosing an emoji toggles it on that item.
  • thread/react writes message_reactions. The primary key is the uniqueness rule: a second click deletes the row.
  • thread/transcript returns the marks. Hydrate overlays them onto the same renderer item ids.

A reaction is not an ACP event. The transcript log stays “what was said.” The marks sit beside it, keyed on the item id hydrate already produces (e{seq}-{counter}).

How to verify

  • ./scripts/verify.sh already passed on the pushed tree (pre-push).
  • Open Chief (or any bot chat), wait for a reply, Tab to Add reaction, Enter, pick an emoji.
  • The badge appears under that reply. Click it again — it goes away, it does not double.
  • Switch away and back, or restart the host: the same marks are on the same bubbles.
  • Escape closes the picker and returns focus to Add reaction.
