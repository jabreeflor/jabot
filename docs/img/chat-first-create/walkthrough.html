Chat-first bot create and agent pills

A bot is a chat you talk to. Create opens a thread; pills are how agents show up inside it.

How it works

Before. Crew → Add a bot opened BotEditorModal. The first field that mattered was WHAT IT DOES. The bot existed only after Save.
Now. New bot / Add a bot writes a blank crew row (name “New bot”, empty instructions, next unused colour id) and opens its standing chat.
Shape. The first message is parsed for a name (You're Scout…, Name:, or a short title line). The whole message becomes instructions via crew/update. Optional role pills apply a template without the form.
Presence. AgentPill is BotMark + name. Header title, other crew as presence, @Name in bubbles, composer @ picker. Colour IDs still select the silhouette.
Secondary. The gear / Crew Edit still opens the editor. A Recruiter draft_bot proposal is an in-chat card (Start chatting / Settings), not an auto-opened modal.

What to look at

How to verify

  1. ./scripts/live.sh up then click New bot. You should land in a chat, not a dialog.
  2. Type You're Scout, a research assistant. The title pill and sidebar row should become Scout.
  3. Open Chief. Header pills and typing @ should offer crew as pills.
  4. Crew → Edit still opens the old form (advanced).
  5. ./scripts/verify.sh
