# Chat-first bot create and agent pills

Evidence for the prototype that makes a new bot a shaping chat and draws
agents as BotMark pills in the thread. Every frame is `./scripts/live.sh shot`
against a real `jabot-hostd` (`--translucency preview --desktop dark`).

| file | what it shows |
| --- | --- |
| `shaping.png` | **Add a bot** opens a standing chat, not the WHAT IT DOES form. Welcome + optional role pills. Header is already pills. |
| `named.png` | First message names the bot (Scout) and becomes its instructions. The row and the title pill update; the editor never opened. |
| `pills.png` | Chief's chat: header presence pills and the composer `@` picker. Monochrome BotMark, not colour circles. |
