Add Playwright visual regression and browser accessibility checks

jsdom cannot paint. This suite drives the real renderer against an isolated jabot-hostd, then fails on pixel drift, painted contrast, and keyboard traps. It is Chromium + WebKit proof of the web renderer — not native Tauri or WKWebView.

How it works

Before

  • Axe in Vitest, contrast off, because jsdom does not paint.
  • Manual docs/img/ shots, no automated baseline gate.
  • No browser keyboard / Escape / focus-restore run in CI.
→

After

  • Each test starts its own Vite + host, temp --data-dir, free port.
  • toHaveScreenshot with pinned locale, timezone, viewport, and maxDiffPixels: 0.
  • Browser axe with contrast on; keyboard specs for tab, trap, Escape.
1 · IsolateFixture starts Vite + jabot-hostd. Never live.sh, never .jabot-dev/.
2 · SeedRPC seeds Chief / fake-acp, a permission ask, or a schedule. UI settles before capture.
3 · AssertVisual, axe, or keyboard. Masks only .when and .sched-next.
4 · Tear downReap the process group and delete only that temp dir.
Visual Dark + light. Desktop 1180×780 and minimum 900×600 on onboarding, stream, Settings. Inbox, New Chat, schedules, PR board are Chromium-only desktop shots.
Axe Contrast on. Critical / serious fail. AXE_EXCEPTIONS is empty — no blanket disable. Moderate / minor attach to the HTML report.
Keyboard Onboarding Escape skip; tab to New Chat / Inbox / Settings with :focus-visible; modal trap + restore; New Chat listbox Escape.

CI never auto-approves. updateSnapshots: "none" and the browser job does not pass --update-snapshots. A changed pixel fails and uploads expected / actual / diff. Default verify.sh stays offline; opt in with --check-browser.

#231 / #256 is now on main. This PR layers visual, axe, and keyboard checks on that shared jabot fixture. Native packaged-app acceptance stays #235.

How to verify

  • Install browsers once: npx playwright install chromium webkit
  • Full suite: npm run test:browser — Chromium + WebKit, visual + axe + keyboard.
  • Smoke (no screenshots): npm run test:browser:smoke
  • Default gate stays clean: ./scripts/verify.sh --fast (no display, no browsers).
  • Opt-in after the usual gates: ./scripts/verify.sh --check-browser

Refresh baselines only on the baseline environment (Linux, Playwright 1.63, those Chromium/WebKit builds, en-US / UTC, 1180×780 and 900×600). Review every PNG under tests/browser/__screenshots__/ before committing. Do not raise maxDiffPixels.
