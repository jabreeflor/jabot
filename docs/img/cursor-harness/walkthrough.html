JaBot · PR walkthrough · #222

Cursor Agent talks ACP. JaBot never passes --force.

Cursor is a reserved catalog preset. The host launches agent acp (or the older cursor-agent acp) and maps the session into the same transcript, permission broker, and Doctor the other engines already use.

How it works

Catalog

  • Id cursor, tier 2, thread-scoped.
  • Launch args are only acp.
  • Onboarding, Settings, New Chat, and the bot editor read the same list.
→

Doctor

  • No agent / cursor-agent → CLI missing.
  • Old --version → outdated.
  • status fails and no API key → logged out.
  • models fails → invalid config.
→

ACP session

  • authenticate when Cursor advertises cursor_login.
  • Permissions stay in JaBot.
  • cursor/ask_question and create_plan are declined so the turn cannot hang.

What is supported — and what is declared missing

CapabilityStatus
