Add subtle Cursor-style window translucency

The chrome stays almost opaque. On macOS a native material sits behind ~96% fills so a faint hint of the desktop reads through the sidebar and main pane. Text, inputs, and raised surfaces never thin out.

How it works

Before · solid backing

The window was opaque. --side and --chat were the chrome and the text colors.

→

After · material + fill

macOS paints HudWindow / HeaderView. New --*-fill tokens overlay at 96%. Solid tokens stay for foreground.

The walkthrough pane above exaggerates the gap so the layering is visible. The product fill is 96%, not 72%.

macOSTransparent window + vibrancy. Dark uses HUD, Light uses header, so the 4% gap does not frost the wrong way.
Reduced transparencyprefers-reduced-transparency clears the material and the data-translucency attribute. Chrome goes solid.
Linux / Windowsapply is a compile-time no-op. No Mica/Acrylic. The window reads opaque.

How to verify

  • ./scripts/verify.sh — the one gate. Includes the new unit tests and the window_fx mapping tests.
  • On a Mac: npm run tauri dev over a busy wallpaper, then Dark and Light. The desktop should be a hint, not a distraction.
  • System Settings → Accessibility → Display → Reduce transparency. The window should go fully solid.
  • Live loop (any OS): ./scripts/live.sh up then ./scripts/live.sh shot --out /tmp/after.png --backdrop dark. --opaque is the fallback.
