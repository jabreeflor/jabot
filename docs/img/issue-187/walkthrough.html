PR #198 · Issue #187

Refresh stays where reviewers can reach it.

The Pull Requests list and detail workspace now place Refresh in full-width view chrome above the scrolling document. Long lists and diffs no longer push the control off-screen.

After: full-width chrome owns Refresh while only the document below scrolls.

How it works

One chrome pattern

.pr-view-chrome is a fixed flex row above .page-scroll, so its right edge follows the view—not the 680px content column.

Both PR surfaces

The list keeps its title on the left. The detail workspace keeps Back, repository context, and GitHub link on the left. Refresh stays right in both.

Behavior preserved

List Refresh still calls pulls.refresh(). Detail Refresh still calls load() and retains its disabled and “Refreshing…” states.
