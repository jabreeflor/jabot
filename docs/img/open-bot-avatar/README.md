# Bot icons drawn by open-bot-avatar

Evidence for switching the built-in bot icons to
[open-bot-avatar](https://github.com/DominikScholz/open-bot-avatar). Every
frame is `./scripts/live.sh shot` against a real `jabot-hostd`.

| file | what it shows |
| --- | --- |
| `sidebar-dark.png` | Chief (Cloud) and Bot Recruiter (Chat) in the sidebar rows, the header pills, and the Crew cluster. |
| `sidebar-light.png` | The same in the light theme. |
| `crew.png` | Crew cards with the new characters. |
| `picker-dark.png` | The editor's "Choose a bot" grid: all eight characters, one per saved appearance ID. |
| `picker-light.png` | The picker in the light theme. |
