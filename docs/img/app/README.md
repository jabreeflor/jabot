## What is real in them

The renderer is the real one, unpatched, served by `npm run dev`. What the
script supplies is the webview bridge a Tauri build would: it answers
`host/hello`, so the sidebar can name the host, and leaves the rest of the
protocol unanswered — the shell's documented "the host has not said yet"
state, where it draws the fixtures in `src/views/mock-host.ts`. Those fixtures
are the curated picture the design work is drawn against, which is why they
are what these images show rather than invented host data.

Two consequences worth knowing before you read a diff against these:

- **Schedules is host data.** #25 has no renderer fixtures, so an unanswered
  `schedule/list` would leave that pane empty. The three jobs in it are
  defined in the script, and their times agree with their crons.
- **The Inbox still says "Checking the Inbox…".** That line is honest: the
  host has been asked and has not answered, and the cards under it are
  fixtures. It is not a bug in the pane.

The clock is frozen at 2026-03-12 14:23 UTC, so a re-shoot is byte-identical
unless the UI actually moved.

## Regenerating

```bash
npm run dev &                    # the renderer, on :1420
node scripts/screenshots.mjs     # overwrites the PNGs here
```

Playwright and a Chromium are not dependencies of this repo — nothing in the
gate drives a browser. Install them wherever suits you (`npm i -g playwright
&& playwright install chromium`) and make them resolvable from the repo root.
