Add a Settings option to rerun onboarding

A person who already finished setup can replay the same first-run cards from Settings. The stored profile stays put until they finish, so Escape or Skip cannot trap them in setup or wipe their name.

How it works

Crew already had this re-entry. Settings now calls the same onRunSetup path:

Settings → Run setup again → seed the draft from the stored profile → same 3 panes → Enter JaBot, Skip, or Escape

The gate never deletes jabot.onboarding.v1 when the takeover opens. onFinish overwrites it. Quitting mid-re-run leaves the old record. Host settings, bots, and threads are not written unless the user changes them on those panes.

What is preserved

KeptOnboarding record until finish; host knobs; bots; threads; devices.
Changed only if the user says soDisplay name and default engine, when they Continue through those panes or Skip with a new draft.
ExitEscape and Skip setup persist the current draft (or the name already stored) and return to the shell.

What to look at

src/App.tsxHands Settings the existing onRunSetup. Storage is not wiped first.

How to verify

Open Settings → General. Scroll to Setup. Choose Run setup again. Confirm the name field is seeded. Press Escape. Confirm the sidebar still shows the same name and the shell is usable.
