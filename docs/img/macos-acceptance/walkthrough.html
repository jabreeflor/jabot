JaBot · PR #253 · issue #235

Add a macOS packaged-app acceptance gate for native integration

Browser Playwright can prove the renderer plus a real Rust host. It uses the Vite transport. This gate covers the remaining native boundary: Tauri IPC, Dock, Keychain, packaged adapters, and updater archives — without pretending a headless compile, or a WebKit browser project, is that proof.

How it works

Before

  • Linux verify.sh compiled the crate and drove jabot-hostd.
  • macOS bundle packed an unsigned .app on main only — 10x minutes, no launch.
  • D-019: no banner has ever been delivered or clicked on Linux.
  • Nothing refused production app data or com.jabot.app Keychain.
→

After

  • A named matrix distinguishes compiled, packaged, launched, and interactively verified.
  • An isolated run launches JaBot.app against temp data + a throwaway Keychain + fake-acp-agent.
  • ipc-connected.json is written only from host_rpc — the webview invoke path.
  • Updater .app.tar.gz + .sig are checked separately from a signed install.
compiledLinux verify.sh. No .app.
packagedIdentity + staged adapter. Headless bundle job.
launchedIsolated run. IPC, fake-acp, Keychain, relaunch.
interactiveDock + notify click. Owner = release cutter.

Isolation (load-bearing)

Acceptance exits 2 rather than fall through to the user’s install. No credentials. No production SQLite. No login.keychain service com.jabot.app.

What to look at

  • docs/macos-acceptance.md — the matrix, owners, and evidence rules.
  • scripts/macos-acceptance.sh — check / package / updater-artifacts / run / release-checklist.
  • src-tauri/src/acceptance.rs — evidence files; refuses production paths; no socket.
  • src-tauri/src/lib.rs + secrets.rs — JABOT_APP_DATA_DIR, JABOT_KEYCHAIN_SERVICE, IPC marker on host_rpc.
  • .github/workflows/macos-native.yml — cheap Linux trigger vs opt-in 10x packaged launch.

How to verify

  • ./scripts/verify.sh — includes the new Linux stage.
  • ./scripts/macos-acceptance.sh check and ./scripts/tests/macos-acceptance.test.sh.
  • On a Mac, after npm run tauri build: ./scripts/macos-acceptance.sh run --app src-tauri/target/release/bundle/macos/JaBot.app. Keep the printed evidence directory.
  • Release: ./scripts/macos-acceptance.sh release-checklist. Notification prompt, click-to-thread, and signed update install stay manual with screenshots.
