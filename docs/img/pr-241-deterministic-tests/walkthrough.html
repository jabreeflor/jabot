Make tests deterministic across machines and parallel runs

The audit at c898b8f had real coverage and intermittent failures. Four of them depended on PATH, socket scheduling, or a partial flush. This change pins the fixture, waits for the complete record, and leaves the suites parallel.

How it works

Before

  • Chief handoff assumed no Claude on the box. A real CLI made dispatched true.
  • OAuth loopback dropped a CSRF GET when the accepted socket was still nonblocking.
  • Mobile inbox waited for permission_reply=, then required allow_once on a half-written line.
  • Bot-icon FileReader/Image and fold’s 380ms leave animation raced the default 1s findBy.
→

After

  • Chief fixtures pin jabot-test-absent at /jabot-test/no-such-agent. Not a catalog launch, so recover cannot swap in Claude.
  • Accepted loopback sockets are blocking with a 5s deadline — same as LocalAuthServer.
  • Waiters parse a complete permission_reply= JSON line and read optionId.
  • Image decode is stubbed and flushed inside act. Fold waits for the host mock first, with a 3s budget.
