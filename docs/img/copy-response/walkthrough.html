JaBot · PR walkthrough · #267

Add Copy response to assistant chat bubbles

Users had to highlight an assistant reply to reuse it. Every assistant bubble now has a compact overlapping-squares control that copies that reply’s source markdown — and only that reply.

How it works

Before

  • Assistant text sat on the page with no chrome under it.
  • Reuse meant selecting through rendered markdown.
  • Fences, line breaks, and neighbouring stamps came along for the ride.
→

After

  • AgentBubble draws a msg-actions row under the bubble.
  • The button writes item.text — the source, not innerText.
  • The same control says “Copied” or “Couldn't copy to the clipboard”.

Bot chats and Code conversations share Conversation → Transcript. One row covers both. Reactions (#265) and branch (#266) are meant to sit in the same group.

How to verify

  • Open a bot chat or a Code thread, send a turn, hover the overlapping squares — tooltip is Copy response.
  • Activate it (click or Enter). Paste somewhere: the markdown source, not the rendered list or fence chrome.
  • A user bubble, a stamp, and “Session finished.” stay out of the clipboard.
  • The button keeps the name “Copy response”; a live region announces the result.
  • ./scripts/verify.sh passed on the pushed tree.
