Before

How to verify

  • npm run lint — clean tree, then the two probe lines.
  • Write a hook behind if or an effect with [] that reads a prop; npx eslint on that file must fail; delete it.
  • ./scripts/verify.sh --fast includes the lint stage. Full ./scripts/verify.sh is the same gate CI runs.
  • To extend later: add the #225 / #226 rules in eslint.config.js. Do not add a second linter.
