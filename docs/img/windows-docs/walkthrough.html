Add Windows install docs and smoke acceptance checklist

macOS already has a packaged-app gate. Windows is the #280 tracking epic and is not macOS parity. This PR names how to install (when an artifact exists), how to run tauri dev, the gaps vs the Mac app, and five smoke cells — without claiming a shipped .exe.

How it works

Before

  • README and install.sh were macOS-only.
  • bundle.targets is still app / dmg. Release builds universal-apple-darwin.
  • Gaps (glass, Dock hide, SmartScreen, notify) lived only in child issues.
  • Nothing stopped a later PR from inventing a second Windows page.
→

After

  • docs/windows.md is the one install + gap page. Sibling PRs update the table, not a fork.
  • Five smoke cells, not Dock / Keychain / updater archives.
  • Linux check refuses production %APPDATA%\com.jabot.app and the production secret service.
  • run dies on purpose until #281 publishes an installer.
launchNative window + Tauri IPC. Not live.sh.
bot chatCreate or open a standing thread.
secretOS store round-trip. Memory backend is not a pass. #283.
adapterACP child starts. fake-acp is enough.
