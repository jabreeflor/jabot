# Gemini CLI harness (#219)

Real Vite renderer + `jabot-hostd` via `./scripts/live.sh`. Gemini is a
shipped catalog card: New Chat can pick it, Settings can enable or disable
it (with capability notes), and first-run onboarding runs Doctor against it.

| File | What it shows |
| --- | --- |
| `new-chat-picker.png` | New Chat harness menu includes Gemini CLI |
| `settings-harnesses.png` | Settings toggle + capability notes (`session/load`, no resume/close) |
| `onboarding-engine.png` | First-run engine picker + Doctor: missing CLI, install into `~/.local` |
