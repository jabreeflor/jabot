Keep one search on the Pull Requests screen

The PR board now has one clear filtering control. The redundant “Open any PR by URL” form is gone, while the retained search still covers every row in the unified board, including open PRs loaded for the signed-in GitHub account.

The remaining control filters the same combined list users came to this screen to manage.

How it works

  • pr/mine rows are folded into the board when GitHub is signed in.
  • The search matches title, repository, and #number across those rows.
  • Tabs still choose Open, Merged, or Drafts; search narrows the selected tab.

What to review

  • src/views/PullRequestsView.tsx removes the URL form and its local state.
  • src/__tests__/github-signin.test.tsx proves one search filters an account-owned PR and the old controls stay absent.

How to verify

  1. Open Pull Requests while signed in to GitHub.
  2. Confirm there is one PR search and no “Open any PR by URL” field.
  3. Search by a title, repository, or number from one of your open PRs.
  4. Run npm test -- --run src/__tests__/github-signin.test.tsx src/__tests__/pull-requests.test.tsx src/__tests__/pulls.test.tsx.
