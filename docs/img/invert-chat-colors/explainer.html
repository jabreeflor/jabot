Inbound cream, own graphite

Chat bubbles swap sides of the cream/graphite pair. Inbound (left) is cream with dark ink. Your own messages (right) are graphite with light ink. The rest of the shell — primary buttons, selected tabs, pressed tool chips — stays cream.

Before and after

How it works

--bub-bot is now the cream inbound fill; --bub-me is graphite. A new --cream token keeps primary chrome on the old high-contrast fill so tabs and .btn.primary do not go dark with the own-bubble. Inside an inbound bubble, fenced and inline code keep light ink on the sunk ground so markdown stays readable on cream.

What to look at

  • src/styles/tokens.css — bubble tokens and the cream chrome fill.
  • src/styles/chat.css — inbound ink on .bubble, light ink on code inside a bot bubble.
  • src/styles/shell.css, cards.css, modal.css, schedules.css — primary chrome now uses --cream.

How to verify

Run ./scripts/verify.sh --fast. In a browser preview of the Vite app, open Chief: the left bubble is cream, the right bubble is graphite, and Disappear until done is still a cream button.
