JaBot · PR walkthrough

Simplify bot icons
to solid circles

Default bot icons use their existing colors as flat circles. The Crew icon combines three smaller circles.

How it works

Before

A sprite-sheet image animated inside a gradient tile.

After

A decorative span uses the bot color and a 50% corner radius.

Uploaded pictures retain their override and use the circular crop. Accessible names, unread dots, and activity rings retain their behavior.

Rendered app

Browser preview with fixture conversations; the offline host status is expected in this preview.

What to review

  • src/components/avatar/Avatar.tsx replaces the default atlas with ColorMark and shares it with Crew.
  • src/styles/avatar.css defines the solid palette, circular crop, and existing status indicators.
  • src/components/avatar/__tests__/avatar.test.tsx covers default colors, image overrides, and status indicators.
  • src/__tests__/bot-icon.test.tsx checks the editor returns to a solid mark after removing an upload.

How to verify

Run NODE_OPTIONS=--no-experimental-webstorage ./scripts/verify.sh. Open the app and check the sidebar, Crew cluster, and chat header. In the icon editor, upload a picture and then remove it: the circular color should return.
