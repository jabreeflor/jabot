Windows Inbox toasts (or soft-fail)

#284 / #280. Windows now has its own notify backend. It posts an Action Center toast, or it logs and returns. It never panics, and it never borrows the Linux no-op. macOS mac.rs is untouched.

How it works

Inbox write persist-then-notify. The card is already on disk.
→
notify::plan portable. Same title/body/kinds on every OS.
→
backend mac / win / unsupported. Chosen at compile time.

A refused toast costs the interruption and nothing else. That is decision #5, unchanged.

1. Windows is a third backend, not a silent Linux mod.rs now splits mac / win / unsupported. Linux CI still compiles the no-op. Windows reports supported: true and notDetermined until a toast is accepted.
2. WinRT toast, title and body from the existing plan win.rs posts a WinRT ToastNotification with the same NativeNotification macOS uses. Only needs_you, done, and failed ring. The notification and its Activated handler stay alive after Show so a click can still fire.
3. AUMID, then a documented fallback Try com.jabot.app (the Tauri identifier). If WinRT refuses — typical for unpackaged tauri dev until #281 registers the id — retry once as PowerShell's well-known id and say so in the log. A PowerShell success does not skip the real id next time. Any remaining error is eprintln and return.
4. Click uses the macOS sink, while the process is alive Activated calls dispatch_click. lib.rs focuses main and emits notification-activated. The WinRT objects are retained so this still works after post returns. After quit, Windows does not relaunch — that is installer/COM work. The card is already in the Inbox.

How to verify

  1. ./scripts/verify.sh on Linux — unsupported path + portable tests.
  2. ./scripts/verify.sh --check-mac — mac.rs still lints. win.rs is cfg(windows) and is not this scratch crate.
  3. On a logged-in Windows 10/11 session: fold a thread or wait for needs_you / done / failed. Confirm the toast title/body, click it while JaBot is running, then turn notifications off and confirm the host does not crash.
